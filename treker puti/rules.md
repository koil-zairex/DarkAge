# Правила проекта «Трекер привычек»

## Контекст
Приложение для ежедневных привычек. Стек: React + Tailwind CSS, JS, без TS и без роутера.
Уровень разработчика: начинающий.

## Структура
- index.html — разметка
- src/App.jsx — состояние, роутинг по табам
- src/pages/ — 4 страницы: TodayPage, HabitsPage, StatsPage, SettingsPage
- src/components/ — NavBar, HabitItem
- src/mockHabits.js — моковые данные
- src/storage.js — работа с localStorage

## Правила
- Объясняй изменения простыми словами
- Не добавляй библиотеки и фреймворки
- Не создавай новых файлов
- Не меняй файлы за пределами задачи
- Если нужно выйти за скоуп — сначала спроси

## Дизайн

- Стиль: минималистичный, деловой. Без градиентов, без эмодзи, без теней.
- Компоненты: собственные React-компоненты на Tailwind. Новые библиотеки не добавляем.
- Палитра (нейтраль + основной + один акцент):
  - фон: #ffffff
  - поверхность: #f9fafb
  - текст: #1a1a1a
  - вторичный текст: #6b7280
  - граница: #e5e7eb
  - основной: #2563eb
  - акцент: #22c55e — только для главного действия «Отметить выполнение»
- Шрифт: Inter. Размеры: 24 / 18 / 16 / 14. Больше размеров нет.
- Отступы кратны 8px: внутри карточки 16px, между карточками 16px, между блоками 24px.
- Скругления 8px везде.
- Навигация — неглавный элемент: неактивные табы #6b7280, 14px; активный #2563eb, 16px.
- Главное действие на экране Today — отметка привычки. Кружок 28px, граница 2px #d1d5db; выполненный — заливка #22c55e, галочка белая.
- Новые элементы оформлять в стиле существующих. Перед добавлением сверить палитру, размеры, отступы.
